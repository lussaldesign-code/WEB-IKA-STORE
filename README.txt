# IKA STORE Website

Website statis responsif untuk IKA STORE.

## Cara menjalankan
1. Ekstrak folder ZIP.
2. Buka `index.html` di browser (Chrome, Edge, Firefox).
3. Untuk dipublikasikan, unggah `index.html` ke layanan hosting statis seperti GitHub Pages, Netlify, atau hosting milik Anda.

## Fitur
- Desain responsif bernuansa pink dan ungu mengikuti referensi.
- Daftar paket Axis, Telkomsel, By.U, Indosat, dan XL sesuai pricelist yang diberikan.
- Pencarian paket dan filter operator.
- Tombol WhatsApp langsung ke 0851-4799-4829.
- Navigasi ke bagian Beranda, Pricelist, Kontak, dan Tentang Kami.

Catatan: harga dan deskripsi ditampilkan sesuai data yang diberikan. Perbarui file `index.html` jika harga berubah.

Background: assets/waguri.png (gambar Waguri yang diberikan pengguna).
Pastikan folder assets tetap berada di samping index.html.
